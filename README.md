# Hallstatt 哈修塔特 · 即時渲染遊戲場景

**線上試玩：<https://weiyu168.github.io/hallstatt-webgpu/>**（建議用最新版 Chrome 或 Edge；第一次載入約需數秒）

兩個版本共用同一套第一人稱操控：

| 頁面 | 內容 | 渲染 |
|---|---|---|
| `index.html` | 程式生成的小鎮（配色與材質參考實景照片）：湖面倒影、彩色木屋、石砌新教教堂與深色細長尖塔、山腰天主教堂、市集廣場、碼頭、小船與綁骨架的船夫、疣鼻天鵝、柔和的程式雲，加上 7 張明信片收集任務與 4 個時段 | Three.js WebGPU（不支援時自動改用 WebGL 2） |
| `splat.html` | 載入 World Labs Marble 匯出的高斯世界（`.spz`）與碰撞網格（`.glb`） | Spark 2.1（WebGL 2） |

## 執行

**雙擊資料夾裡的 `啟動遊戲.bat`**，它會在本機開一個小型網頁伺服器，並自動用瀏覽器打開遊戲（建議 Chrome 或 Edge）。玩的時候請讓那個黑色視窗保持開著，關掉視窗就會停止。

> 不要直接雙擊 `index.html`：瀏覽器的安全限制會擋下 `file://` 網頁裡的 JavaScript 模組，畫面會一直停在「載入中」（現在網頁會改成顯示提示）。

- 需要 Python 3（安裝時勾選「Add python.exe to PATH」）。
- 第一次載入需要連上網路，從 cdn.jsdelivr.net 下載 three.js。
- 也可以手動啟動：`python serve.py`（自動找空的連接埠）、`python serve.py 5180`（指定連接埠）、`python serve.py --no-browser`（不自動開瀏覽器）。`serve.py` 會送出不快取的標頭，修改程式後重新整理就能看到最新版本。
- Claude 的預覽設定（`.claude/launch.json`）使用連接埠 5174。

載入時，材質會在 4 個背景執行緒（Web Worker）平行產生，和 WebGPU 初始化同時進行。各階段花的時間會印在瀏覽器主控台（F12 → Console），總秒數也會顯示在開始畫面下方。

## 操作

WASD 移動 · Shift 奔跑 · 空白鍵跳躍 · 滑鼠或方向鍵轉視角 · E 上船／下船 · P 明信片冊 · M 背景音樂開關 · T 切換時段（清晨／正午／黃昏／夜晚）· Q 切換畫質 · Esc 暫停

**畫質**：以螢幕原生解析度渲染（Windows 縮放 125% 時就是 1.25 倍），搭配抗鋸齒與局部銳化。預設「自動」：幀率太低時依序降級（MSAA → SMAA → 解析度 0.9 → 0.8 倍，最低 0.85 倍 CSS 像素），很順時再升回去。按 Q 依序切換：自動 → 固定極致（MSAA）→ 固定高（SMAA）→ 固定省電。目前畫質顯示在右上角。

**背景音樂**：《Above the Treeline》，第一次點擊或按鍵後開始播放，循環時會跳過頭尾的靜音；開啟明信片時自動調小聲。按 M 開關，選擇會被記住。

乘船時：W／S 划行、A／D 轉向、Shift 加速、V 切換第三人稱／乘客座位視角（划槳船上可以看著船夫面對你划槳），靠近碼頭或岸邊按 E 下船。

## 明信片

7 個景點各有一張漂浮的明信片（湖心那張要搭船）。收集時，遊戲會以預設構圖渲染景點畫面，在 Web Worker 中轉成「寫實手繪水彩＋墨線」（Kuwahara 濾鏡、顏料邊緣、紙張纖維、鉛筆斜線、手繪抖動墨線、不規則筆刷邊界），再放進藝術明信片模板（紙膠帶、郵票、郵戳、德文手寫問候）。

## 檔案

- `啟動遊戲.bat`、`serve.py`：雙擊啟動的本機伺服器
- `assets/audio/above-the-treeline.mp3`、`src/music.js`：背景音樂與播放控制
- `src/texgen.js`、`src/texture-worker.js`：材質像素運算（可在背景執行緒執行）
- `src/textures.js`：程式產生的無縫材質（石板路、石牆、日曬木板、石板瓦、立邊鐵皮屋頂、灰泥、格子窗與蕾絲窗簾、遮陽棚條紋、天鵝羽片、草地、水波法線、雲的雜訊、山腰雲霧帶）
- `src/terrain.js`：湖岸線、湖底剖面、地形高度函式、群山、雲杉林
- `src/village.js`：房屋（屋簷椽頭、老虎窗、陽台欄杆、花箱、百葉窗、窗台、轉角飾帶、一樓遮陽棚、灰色鐵皮／石板屋頂）、教堂（石砌牆、尖拱窗、扶壁、玫瑰窗、鐘面）、廣場、石板路、路燈、碼頭、船屋
- `src/vegetation.js`：隨風擺動的草叢、野花、湖岸蘆葦、巨石
- `src/boat.js`：曲面木船（划槳船、遮陽棚電動船）與乘船遊湖操控、航跡浪花；船身內有只寫深度的「擋水蓋」，湖面不會從船底透出；槳葉入水時立槳並濺起水花；電動船有舵柄
- `src/human.js`：程式建模＋骨架綁定的船夫（SkinnedMesh、17 根骨骼、線性混合蒙皮），以雙骨 IK 讓雙手握住槳柄、雙腳踩在船底，隨槳的節奏前傾後仰、偶爾回頭看航向；開電動船時握舵柄
- `src/loft.js`：沿斷面環放樣的網格工具（人物與天鵝共用）
- `src/props.js`：停泊的船與纜繩、疣鼻天鵝（放樣的身體與 S 形長頸、拱起的雙翼與飛羽、橘紅色喙與黑色肉瘤、羽片法線貼圖）、綠頭鴨、飛鳥、水面漣漪
- `src/sky.js`：天空穹頂上的兩層程式雲（層積雲：域扭曲、沿風向拉長、依太陽方向打光、邊緣透光與銀邊；卷雲：細長羽絲）、山腰低垂的雲霧帶、湖面晨霧
- `src/decor.js`：Mühlbach 瀑布、煙囪炊煙
- `src/postcard.js`、`src/spots.js`：手繪水彩明信片系統與景點介紹
- `src/water.js`：清澈湖水（依水深漸變、透明可見湖底、流動波紋、菲涅耳反射、太陽閃光）
- `src/world.js`、`src/player.js`：碰撞與第一人稱控制
- `src/quest.js`：明信片任務
- `src/splat-main.js`：Marble 高斯世界載入器
- `marble/README.md`：從自己的照片生成高斯世界的步驟
